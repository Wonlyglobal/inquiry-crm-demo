# Grace 私有日报、周报和证据

仅沿用智能体世界已授权的精确 active owner 身份，不扩大成员、客户或物料权限。内部资料不得进入公开 Git、公开物料或外部模型。

- 设置中“私有知识同步”接受最多256KB、5份文档的内部知识包。
- private-intelligence-import 使用当前JWT调用受控RPC；每包原子提交并审计，版本只追加、SHA256去重，拒绝旧生成时间覆盖新版本。
- private-intelligence-receipt 回读本人知识编号、校验值和导入时间。逐份核对后才显示验证成功；回读失败不能声称全部收到。
- “查看上周周报”“查看新增证据”“查看2026-10-12到2026-10-18周报”走内部只读RPC，上周按北京时间计算。区分报告期间、源生成/发布日期、发现时间和导入时间。
- 内容不进入对话向量记忆、模型提示或外部语音合成；语音只用固定回执，保留原声纹门禁。
- 新版本表开启RLS，匿名和authenticated无基础表读写权；RPC再次核验精确身份、邮箱、启用状态和owner角色，读取/回执也审计，无删除接口。
- 始终标记自动汇总、未经人工事实核验，不把部分提取、过期、缺失或失败当作完整理解、零值或没有变化。

从最新干净工作树运行：

```sh
python3 scripts/prepare-private-intelligence.py --source-dir '<项目私有目录>' --date YYYY-MM-DD --output '<项目私有目录>/grace-sync-bundle.json'
```

仅处理已授权的最少汇总和公开证据；输出拒绝Git目录。随后在原授权Grace会话选择该包，点击“同步并回读验证”，再对话核对报告编号、日期、来源和缺口。没有会话或未完成回读时保留本地报告、记录尚未同步；不提取或复制登录令牌，不以服务密钥替代用户。

验证：离线回归、真实处理器隔离调用、PGlite 0.5.10合成SQL（权限、幂等、版本、原子回滚、审计失败及恶意字段/链接）和浏览器正负向验收。上线以实际部署审计与生产检索回读为准。

回滚：先撤销三个新RPC的authenticated EXECUTE，再按正常PR恢复前端/函数；保留版本表和全部审计，不删除已同步证据。

刷新后可在同一卡片点“回读已同步知识”，只读取最近五份知识的编号和校验值并逐项核对，不重新写入报告。失败只标未完成，不清除已保存版本。

### 报告阅读与连续追问（2026-10-19候选）

报告在公司服务内将既有结构字段转换成中文说明，保留原始数值、来源日期、统计口径和未核验状态；缺失、空数组与零分别展示。默认收起来源明细，可点“查看来源与缺口”。回执按报告类型/日期展示，编号和SHA-256折叠保留；只有所有回执一致才展示成功卡片。

“风险呢”“下一步呢”“它的来源有哪些”等明确短追问沿用最近一次成功单份报告的key，最长10分钟；开始新需求、其他话题、失败、停止、切换智能体或退出时清除。客户端只在内存保存key和时间，不保存报告正文，也不将内部回答加入外部模型历史。服务端严格校验key，每次仍走原owner受控RPC；声纹验证先核对原始转写，再解析追问。快捷按钮固定到该卡片的报告，不依赖当前其他对话。指定单日日报精确查当天，“昨天”“本周”“上周”使用北京时间；未同步的日期明确返回未找到，不用较晚报告替代。

本改动不迁移数据库、不变更RLS/账号权限/声纹门禁、不导入新报告或公开物料。上线及真实回读以部署审计为准。

### 四平台每日逐帖私有快照（Facebook / YouTube 扩展）

沿用原 owner、metrics-only 固定源接口、私有 RPC 和原每日任务，新增 facebook-YYYY-MM-DD / youtube-YYYY-MM-DD，与 TikTok、Instagram 分开追加；不覆盖日报、周报或竞品证据。每平台最近28天、最多100项，保留源分页和时间上限、完整性与未知指标。Facebook 独立观看者单列，不冒充触达；不支持的 insight 不抹掉其他已知指标。YouTube 固定 WONLY 频道，仅公开视频的观看/点赞/评论累计值，不读取标题正文、评论身份或私有 Analytics；不可见视频、分页/时间截断均保留缺口。仅完整窗口内返回明细可称本次有界覆盖完成，不能称全历史。

同步按钮写入四份快照后分别核验回执和完整文档；失败不自动重写，来源失败沿用历史成功时间，旧明细明确标历史。新需求分别问“查看今天已同步的Facebook指标”“查看今天已同步的YouTube指标”，核对当日key、同编号/完整SHA-256、来源日期、窗口、帖子数和逐项未知；刷新后只读回执再次核对。无会话、缺权限或源失败时明确未完成，不提取Token、不扩大平台权限或以服务角色代替原用户写知识。数据只入公司私有库及本地私有artifacts，不进公开仓库/物料/外部模型。

每日09:00沿用grace-brian-jay，依赖本机在线及有效CRM会话；配置不等于未来首次自动执行已验收。生产上线状态见WORKLOG及部署审计。
