## 范围与实现

本次仅扩展受控询盘导出的管理范围。保留 profiles.team；新增私有主管范围表和不可修改/删除的授权审计，普通账号及 service_role 无直接读写权限。8 个导出相关函数统一检查明确范围，涵盖申请、列表、预览、审批、撤回、领取复核与通知。未配置范围的主管沿用原同团队权限；一旦存在明确范围，只有 active=true 的授权团队有效，停用全部授权不会回退到原团队。

生产操作脚本按唯一有效账号“凌子学 / sales_manager / 销售部”核对，再仅添加海外业务部、海外工程部。不存在、重复或已有配置时停止，禁止静默覆盖。记录用户授权原因与独立审核链接。审核链接格式检查只是防误操作，执行人仍必须通过 GitHub API 核实真实批准及确切提交，不能用字符串代替独立审核。

不包含测试团队，不授予其他销售主管这两个部门，不改变员工部门、客户归属、邮件/附件 RLS、风险中心或外部 AI 授权。两个部门仍分别申请，不允许一个申请混合团队；双审批、申请人回避及一次领取保持。凌子学自己的申请仍需另一位有权限主管，不允许自审。
