# 日报填写流程优化（2026-10-28）

用户要求没有业务员账号时继续优化日报。保留日报/线索统一账本、服务器录入时间、草稿与正式状态、角色范围和提醒规则。

增加三步操作引导、文字提示、固定保存/提交栏；编辑状态可读、保存中和失败状态明确。切换日期、返回及常用导航提示未保存修改，刷新由浏览器原生离开保护处理；取消切日恢复原日期和文字。只内存比较原服务器文本，不在localStorage存客户内容，不自动提交。

正式提交前核对日期及当前新增/转化，最终仍由服务器核算并锁定快照。管理范围内列出尚未正式提交的人，模拟/草稿不冒充正式提交；读取失败不输出缺交结论。该名单仅按原scope，非考勤或人事判断。
