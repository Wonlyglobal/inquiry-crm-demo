# 邮件原始日期修复候选

用户要求邮件沟通按真实收发时间，不用导入时间。普通同步原来在 parsed.date 缺失时使用 new Date()；历史回补优先 INTERNALDATE，该日期可能因邮箱导入而改变。候选以原邮件 Date（解析日期或 IMAP envelope 日期）为时间；没有可用 Date 时不伪造当前时间。Date 是发件方声明的邮件时间，不是独立校验过的 SMTP 送达证明。

普通同步在现有 raw_headers 中增加 original_date/date_source，不新增表或权限；收件/发件分别存对应字段。历史回补按 envelope Date 筛选和存储，无日期仅跳过并计数，不用 INTERNALDATE。前端按方向取时间，原始日期优先，未知排在最后，旧数据无来源显示待核对；识别面板使用同一原始时间并拒绝明确 unavailable 时间。
