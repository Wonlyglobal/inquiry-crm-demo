# 每日线索与个人商机

授权：项目负责人于2026-10-26确认规则并要求完成测试、数据核对后上线；执行Codex。

新增私有线索账本、按日规则快照、仅追加事件及周报快照。现有公司/联系人/商机不批量回填或改归属；转化显式调用现有 create_customer_opportunity，沿用它的归属冲突检查，单线索锁定且幂等。不同线索关联同一商机时商机量按ID去重。

每日按实际服务器录入时间（北京时间）统计，获取日期仅作来源事实；手动/Excel均记录方法，批次200行/2MB，本地预览确认，不上传Excel原文件。无新增原因与新增数分开；周末免录，节假日/休假由市场部或老板登记。规则新版本仅未来日期生效，不回写历史；不自动从考勤系统获取假期，不预装未经确认的节假日表。

业务员仅读写本人；主管仅原授权团队只读；市场部/老板查看本模块全员线索和关联商机的阶段/预计金额及业务员主动填写的共享跟进摘要。不得借此读销售私有邮件、报价文件、合同或付款。没有新建这些表的SELECT策略，没有外部AI，不发客户邮件，不改绩效或认定员工过错。新工作台读取有范围/条数审计。

工作日17:00提醒本人及直属主管，周五16:00生成周报。数据库任务每分钟判断实际规则，持久化站内通知与飞书发件队列；飞书复用既有群机器人，只含成员名与完成数量/状态，不含客户身份、联系方式、需求、金额或跟进原文。群提醒不等于个人私聊/@到人。发送失败5次上限、10分钟租约，网络结果不确定时可能重复，不能承诺外部恰好一次。

周报保存截止时间和规则ID，不因补录重算；新增按录入日期、本周转化按转化时间；转化率为当周录入线索当前已转化比例。阶段及跟进针对本模块关联商机，不冒称所有旧CRM商机已迁入。周五16:00快照的“未提交”指截止尚未提交，不等同17:00逾期。

商机明细及周报阶段以主CRM同口径中文展示（待分配、收到询盘、有效询盘、已联系、已报价、已寄样、谈判、成交、丢单）；数据库枚举与历史快照不修改。未关联商机显示“尚未转化”，已关联但无可读阶段显示“阶段暂不可用”，未识别阶段显示“阶段待核实”。

回滚：先停 cron 的 crm-sales-lead-schedule、crm-sales-lead-dispatch，再撤入口/函数；撤新RPC执行权并保留账本、周报、事件、已转化商机及原审计。不得删真实线索或回退原商机归属。调度凭据及飞书地址只在既有Vault/Edge Secrets中读取，不入仓库或浏览器。
