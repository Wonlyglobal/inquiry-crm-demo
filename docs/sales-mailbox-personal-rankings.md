# 业务员个人邮箱数据榜

用户要求将已连接业务员邮箱数据纳入个人排行榜（2026-10-23）。此变更只使用当前看板已有的get_sales_email_activity_metrics返回结果，不新增数据查询、数据库迁移、权限或评分规则。

排行榜新增阿里邮箱已同步总发件榜、总收件榜，和每人完整明细：阿里收/发、CRM开发信、已关联有效客户来信、CRM回复、7天开发信回复率、24小时内回复/中位分钟、待回复/超时、AI待复核、连接状态及最近同步。复用现行本人/团队/老板及上层团队/人员筛选，不扩大可见范围。

统计月份明确显示，阿里邮箱数量来自当月daily.total_sent/total_received，不把仅CRM成功审计的development_sent误当全部发件。只计有效日期、当月且不晚于今天的行；重复日/畸形数字或字段缺失不累加。未连接、无同步时间、同步异常、同步时间未覆盖所选月份、RPC行缺失、整体读取失败都不作为邮箱0参加数量榜。已加载稀疏结果中没有记录可以显示已同步数量0，但不称原邮箱全量无邮件。0不评第一；并列数量使用同名次。

原CRM开发信数量榜和至少5封成熟样本的7天回复率榜保留，不修改员工评分。个人表的无分母回复率显示—，产品/市场/人事结论不由数量决定。当前接口不提供各文件夹和完整历史覆盖证明，因此页面一直注明仅已同步记录，非全量验收。
