# 指定文件的后段页定位修复

PR543/v197线上验收发现：普通保养问题及连续追问能引用P68；复制该出处中的完整PPTX文件名提问，却出现当次未命中。原失败留存，没有记作通过。

只读核对当前物料服务器接口源码（2c5e3023）发现：完整文件名结尾的query触发整文件直查，页选择绕过内容条件，先返回最前6页，无法取得后段保养页。本地物料仓库接口与生产版本不同，本修复以实际生产契约为准。

调整仅涉及查询计划：文件名放入服务端AND条件，query使用内容主题；回答端仍严格核对原文件名、版本、页码与证据门禁。不能用其他文件命中的段落补答指定文件。新增真实handler合成断言，保证文件名约束仍在、查询不再触发前6页分支且能回答后段P68。

不修改源服务器接口、索引、角色/RLS、Secret、公开范围或外部模型调用。完整v197包可回滚；部署后须用线上失败原题复验，不能用离线测试替代。此文为候选说明，发布状态以验收记录为准。
