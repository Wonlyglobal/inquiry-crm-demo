# 产品专家档案与验收

本阶段：按本次授权检索返回的逐页证据建立型号档案。不是全库覆盖报告；不新增资料外发、数据库权限或专家自动批准。

## 验收顺序

1. 全型号清单：以公司正式目录为准；检索未出现的型号也须纳入后续清单，不能用有提取结果的型号替代全量目录。
2. 逐型号八维档案：系列型号、材料结构、配置功能、性能条件、标准认证、场景限制、安装维护、交付售后。
3. 原文核对：每项关联文件版本和页码；历史版本不得当现行依据。型号别名和冲突不能自动合并或裁决。
4. 专家验收：使用实际手册建立预期答案，保存在公司私有系统；公开仓库只放合成测试。当前无审核写入接口，不把人工确认存入模型记忆冒充审核。
5. 选型规则：取得适用条件、排除条件和负责人核验后再用于确定性推荐。
6. 竞品分析：仅已批准公开证据，测试标准和配置不同不得直接排名。

## 每型号验收题型

- 明确参数：给定型号，回答尺寸/材质等并提供页码。
- 跨页关联：配置页和性能页是否对应同一型号及配置？
- 版本冲突：旧手册和新手册有不同数值时，分别呈现并解释缺口。
- 限制条件：是否能用于指定场景；缺条件时先询问。
- 认证边界：证书是否覆盖该型号、尺寸、配置及有效期？未核验时不判合规。
- 拒绝误配：相近型号、组件型号不能自动当主产品。
- 负例：不存在的参数或没有资料的问题，明确缺依据。
- 更新回归：新版本到达后，旧事实不得无提示沿用。
