# 跟单全公司受控导出

项目负责人明确批准的单用户例外。此功能独立于原同团队固定询盘清单的双审批，不修改原角色、客户RLS、其他用户审批或数据归属。

- 后台精确绑定申请人及指定审批人的ID、邮箱、角色和启用状态；普通账号无入口且RPC拒绝，账号停用、角色变化、授权版本变化或风险限制阻止领取。
- 类别：客户公司、联系人、线索、商机、跟进、报价。全历史或按北京时间创建日期过滤；线索按实际录入日期。排除测试、归档、合并来源及排除记录；所有数据固定字段投影，不导出原邮件、附件或银行/证件/密钥专门字段。跟进自由文本仍需审批人核对，未实现DLP。
- 申请用途必填。服务端构建不可改快照和SHA256，审批人先查看实际快照再批准/驳回；申请人不能自批。批准后10分钟内一次性CSV领取，逐行含申请号、申请人、时间和快照SHA。CSV为类别/记录ID/字段/值/追踪标识长表，可用Excel打开。
- 授权、申请、快照查看、批准/驳回、撤回和下载均记录于私有事件表，拒绝更新删除；普通身份不能直读私有授权/快照。页面显示每次申请处理记录。列表最近100条，历史仍保留。
- 每小时最多5次、同时最多3个未完成申请，20MB快照上限，超过应按类别/周期分批。下载只由服务器生成；网络失败可能已消费，需重新申请，已保存文件无法远程收回。
- 工程部署只读核验账号和结构，不替用户申请、审批或下载真实客户文件；正式使用由两个真实账号分别操作。隔离SQL使用合成资料，不伪造生产身份。
- 回滚优先停用该精确grant（触发审计及版本递增），阻止在途领取；保留请求/快照/事件，不删除审计。前端可以正常revert。

## 本轮验证

隔离PGlite实际执行24项断言：申请人/指定审批人分离、无关owner拒绝、直读私有表拒绝、同范围六类各1条、原客户/商机/报价不改、未批/重复领取拒绝、哈希不一致拒绝、公式注入转义、回收站/测试排除、快照及审计不可改、授权撤销/版本变化/风险控制与匿名拒绝。合成UI分别核对申请六类/周期、审批快照及理由入口，无真实客户/邮件/批准动作。

全量1590测试在Asia/Shanghai时区通过。主机Europe/Madrid下原有展会报名倒计时用例出现31/30天差异，与本次导出无关，未改该逻辑；业务导出周期显式使用Asia/Shanghai。

## 2026-11-12 指定负责人直接导出例外

项目负责人明确授权李铧燕本人无需审批，直接导出并逐次留痕。通过独立grant的direct_download标志生效，默认false且仍要求当前owner角色；不是对所有owner放开。本人导出记录标注direct_authorized而非伪造本人批准。原用途、类别、周期、固定字段、风险限制、审计、版本/账号复验、CSV追踪和单次领取保持。

同一账号既作为申请人又作为审批人时，列表包含其本人及其待审批记录；每条记录分别返回can_approve/can_download。李铧燕仍能核对并审批陈笑喻的pending申请，不能领取陈笑喻文件，陈笑喻不能伪造direct参数绕过审批。停用李铧燕本人direct grant后仅退回陈笑喻审批身份，不影响陈笑喻原grant或记录。

隔离45项SQL断言覆盖上述两种身份并存、直接导出、留痕、单次领取、授权回退及原24项边界。生产验收只核对授权和入口，不替任何人导出真实客户文件。
